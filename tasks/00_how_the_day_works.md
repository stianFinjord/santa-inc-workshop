# How the day works

Santa Inc. has hired KPMG. Last Christmas, popular toys ran out, deliveries were slow, and nobody trusted the numbers. Your group is the consulting team. You get the same raw data as everyone else and pick the files you need for your case.

You will take the data through four steps. Think of it as a kitchen:

| Step | Kitchen | What you do |
| --- | --- | --- |
| 1. Raw (bronze) | Groceries delivered, still in the bags | Load each file into a table exactly as it is. Look at it. What seems wrong? |
| 2. Clean (silver) | Wash, cut, throw out what's rotten | Fix formats, remove duplicates, handle missing values, make IDs match |
| 3. Ready (gold) | Cook the dish | Combine tables and calculate the numbers that answer the client's question |
| 4. Serve | Plate it | Build a dashboard and give a 2-minute recommendation to the client |

**Deliver at the end:** one dashboard (with a map) and a 2-minute pitch: what did you find, what should Santa do, and how sure are you?

**Ground rules:** AI help (Genie) is welcome, but check at least one number yourself. Finish the simple version first, then go further.

**Your case:**

- Case 1 – Production: are we on schedule? → start with `01_step0_wish_list.md`, then `case_1_production.md`
- Case 2 – Where should Santa build the next warehouse? → start with `01_step0_wish_list.md`, then `case_2_warehouse.md`
- Case 3 – Are our elves staffed right? → go straight to `case_3_elves.md`
